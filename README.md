# AI Data Analyst

An AI-powered data analytics agent that allows users to interact with databases using natural language.

## Overview

AI Data Analyst converts natural language questions into SQL queries, executes them securely against connected databases, and returns structured results with interactive visualizations and AI-generated insights.

## Key Features

- Natural language to SQL generation
- Database schema understanding
- AI agent with function calling
- SQL query validation and security
- Read-only database execution
- Interactive charts and tables
- AI-generated data insights
- CSV upload support

## Tech Stack

**Frontend:** Next.js, TypeScript, Tailwind CSS, Recharts

**Backend:** Python, FastAPI, SQLAlchemy

**Database:** PostgreSQL

**AI:** LLM with Function Calling

**Security:** SQLGlot, Read-only Database Permissions

**Testing:** Pytest

**Deployment:** Docker, AWS/GCP
